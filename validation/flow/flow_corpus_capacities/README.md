# Flow corpus capacities — seed and rule

Generated by `generate_flow_capacities.py` (repo root). Reproducible from the
files here alone — this README + the script are the record of how, but
re-running the script is not required to use the files.

**Seed**: `20260830` (base), combined with each network's own name into a
per-network `random.Random(f"{20260830}:{name}")` — so adding, removing, or
reordering networks never perturbs any other network's draw.

**Rule**: integer capacities uniform in `[1, 20]`, one independent draw per
edge (Python's `random.Random.randint`). A second, separately-seeded draw
(`f"{20260830}:{name}:nodes"`, same `[1, 20]` rule) additionally assigns node
capacities for a named subset of networks — `water`, `KarlNetwork`,
`grid-graph-5x5`, `psplib-j301_1` — chosen as a small, deliberate subset
(not every network) to exercise the node-capacitated / node-split code path
without doubling the whole corpus.

**File shape**: the server's real toolkit-edges-array capacities contract
(`CapacityHandlers.jl`'s `_parse_toolkit_capacity_json`) — `{"data_type":
"Float64", "edges": [{"source", "destination", "capacity"}, ...], "nodes"?:
[{"node", "capacity"}, ...]}`. Float64 only; the server hard-rejects any
other `data_type` for capacities.
